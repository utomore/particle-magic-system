# ADR-0001：混合粒子模型——解析為主，可選力場層

- 狀態：已採納（2026-08-11）
- 相關：[architecture.md §3.2, §4.6](../arch/architecture.md)

## 背景

粒子系統的運作模型決定核心的純度、可重播性與表達力。需求（Init.md）同時包含適合閉式數學表達的行為（依形狀輻射、數學式軌跡）與偏互動性的行為（收束強度）。系統設計目標要求核心盡可能純函數。

## 決策

採**混合模型，解析為主**：

1. **解析層（主）**：粒子狀態是時間的純函數 `sample :: CompiledSpell -> CastContext -> Time -> ParticleBuffer`，無跨幀狀態。
2. **力場層（可選）**：需要「場對粒子」互動（收束、吸引、渦流）時，以固定時步的純狀態轉移 `step :: [ForceField] -> DeltaTime -> ParticleBuffer -> FieldState -> (FieldState, ParticleBuffer)` 在解析結果上疊加位移場。無力場的魔法完全零狀態。

隨機性以種子雜湊導出（`Chan` 變數），兩層皆完全確定。

## 後果

**正面**：
- 核心天然純函數；無力場魔法可任意快轉、倒帶、平行取樣，測試即「給定 t 斷言輸出」。
- 重播只需 `(Circle, CastContext, dt 序列)`，是網路同步與錄影回放的基礎。
- 力場層被隔離成唯一的跨幀狀態來源，複雜度有明確的邊界。

**負面**：
- 「收束」若走解析路徑必須設計成插值曲線，表達上比自由模擬受限。
- 兩層模型比單一模型多一個組合點（解析結果與場位移的疊加語意）需要清楚定義。
- 粒子對粒子互動在此模型下無法表達（明確列為非目標）。

## 被否決的替代方案

- **純解析式**：最純、最可重播，但收束等互動效果全部要壓成數學曲線，部分效果難以表達，會限制玩法上限。
- **純模擬式（積分器）**：表達最自由，但核心變成全狀態化的 `step`，重播與測試全面依賴固定時步＋固定種子，且十萬粒子全積分的成本沒有必要——大多數魔法行為本來就是可解析的。
